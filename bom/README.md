# 当前工程 BOM

- `components.csv`：参考部件、候选/复用/暂缓状态与规格来源。
- `fasteners.csv`、`fasteners-detailed.csv`：五金汇总及逐件位置清单。
- `printed-parts.csv`：40 个打印零件的模型信息。

CSV 采用 UTF-8 BOM，可用 Excel 打开。未知容量、库存、数量或价格保持未知。部分路径与标识保留R6原始工程名称，仅作为检查追踪，不表示相关原厂资料已分发。

这是工程选型及备料参考，不代表部件已购买或通过适配。当前设计状态、带宽取舍及实物验证边界见 `../docs/known-issues.md`。几何、材料和实物验证完成前不要据此批量采购或打印。

R7选用R23SR目录30cm选项，电气PCIe 3.0 x4，GPU端为物理x16母座；这会减少原计划x8的链路带宽，目录选项不证明库存、交期或实机性能。EPS使用标准ATX12V 4pin的500mm延长线，GPU使用标准PCIe 8pin延长线，两者不可混接。完整线长预算包括报告明确记录的接头与装配余量，ATX24原厂前面出口过渡尚未完整建模，不能把名义长度直接当作实装可用长度。

GPU原厂线底开U形槽需要可拆软绑带；绑带具体采购规格、保持力、绝缘与实装数量尚未锁定。GPU上拔前需松绑并将原厂300mm线自由段前移停放，原厂中转接头留位。未使用的原厂分支和余线均需保留并验证收纳，不以剪线来满足布线。
