# R6 工程 BOM

- `components.csv`：参考部件、候选/复用/暂缓状态与规格来源。
- `fasteners.csv`、`fasteners-detailed.csv`：五金汇总及逐件位置清单。
- `printed-parts.csv`：40 个打印零件的模型信息。

CSV 采用 UTF-8 BOM，可用 Excel 打开。未知容量、库存、数量或价格保持未知。部分路径与标识保留R6原始工程名称，仅作为检查追踪，不表示相关原厂资料已分发。

这是工程选型及备料参考，不代表部件已购买或通过适配。转接线干涉和EPS线长等采购阻断见 `../docs/known-issues.md`。几何、材料和实物验证完成前不要据此批量采购或打印。
