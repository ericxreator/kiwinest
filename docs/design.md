# R6：现有5825U主板、三盘、紧凑独立散热

2026-11-14（来源原始日期为UTC；公开整理使用Asia/Singapore）。**结构评审原型，未制造放行。PCIe转接线端头及其前固定件与CPU保护空间仍有干涉，不能据此购买转接线或打印整机定稿。** 最终数值以 `../evidence/r6-review.json` 为准；已知失败不会在预览或BOM中改写成通过。

本版按照DS_2501系列参考170×170mm、Ryzen7 5825U主板重新布局，复用现有DDR4 SODIMM、M.2和原装圆形散热总成，容量及具体版本保持未知。散热器从PCB元件面向外**硬留40mm**；背部SSD、背板和支柱另计。照片正反版本分别Ver1.2/1.3，端口坐标由照片缩放估算约有1–2mm误差，并非厂家机械图。

## 体积与配置

布局目标本体250×250×255mm，含20mm独立脚座250×250×275mm，17.19L。没有净化器时同样依靠自身风扇散热；净化器适配底座是以后独立可拆附件，本版不计它的风量。外凸线缆插头和使用时显示器/AC线的弯曲空间另留。

| 部件 | 本版安排 |
|---|---|
| 主板 | 现有5825U板竖置右侧，元件面向右，后I/O向后；10mm铜柱、四点螺钉、可拆开放托盘 |
| 显卡 | Zotac ZT-B50620H-10M，5060Ti16GB，220.5×120.25×41.6mm；风扇向左、I/O向后、金手指向下 |
| 电源 | 原厂固定线Enhance ENP-7660B 600W，150×81.5×40.5mm；独立导风罩前进后出；效率等级与原线束以实物版本为准 |
| 三盘 | 三块3.5寸竖放在左前方，147×101.85×26.1mm/盘作为尺寸上限参考；盘间5mm；不是要求购买三块8TB |
| 进排风 | 120mm底进、140mm顶排、CPU右侧直进新风、显卡左侧22mm进气通道；PSU不吸机箱热风 |

| 存储接线 | 三条独立SATA数据线直连主板，无背板；两条电源原厂SATA链分配三盘及风扇集线器 |

选择这只Flex是为了让电源放在三盘上方、位于顶扇左侧，避免SFX的125mm宽/63.5mm高挤入主排风和插头弯曲区域。600W不是本机功耗需求；此处看中有原厂机械图和足够连接器的具体型号。不保证1U小风扇与SFX大风扇同样安静，也不使用换扇/改模组版本。SFX需要另一套内部布局，不能作为本版直接替换件。

显卡兼容以该已排布型号的三维尺寸和单8pin位置为准，不把机箱外尺寸当作显卡上限。更长、更厚或更高的卡须重新核端头、进气和拔卡路径。适合风扇从卡正面吸气的开放式轴流卡；热气由机箱顶扇收集排出。总体上行气流不要求GPU自身吸气方向也向上。

## 固定、装配与维护

主板为四点10mm内内M3铜柱，前后螺钉和承载垫圈完整建模；托盘上下四点连框架。主板板背保留M.2及原背板空间；原圆形散热器整体复用，不凭卖家‘115X孔位’另造AM5扣具。孔位/PCB版本仍需实物合板。

硬盘用每盘四颗原生底面6-32螺钉、0.8mm隔垫与开放托架固定。螺钉进入盘壳的名义深度2.75mm，按Seagate参考图核对；不同硬盘的孔型、允许进入深度和接头朝向仍以实物为准。每盘均先拔数据/供电头，上移15mm停车，再解锁并向前抽出。第一盘还需拆前/左皮及其紧固件、左前立柱底部和顶盖对应螺钉，把该立柱向前移16mm取下；其余三柱和上框架支承留位。底脚设有对应工具孔。不是带线热抽取。

显卡先拆顶盖/顶扇并拔下顶扇线，拔掉GPU8pin，上提40mm，再把电源头移到右侧79mm、向后20mm的停车位。解除IO前夹后，卡先上移12mm脱槽，再向上取出。电源、三盘、主板及转接线座留位。主板背螺钉与显卡上拔柱名义最小间距仅0.7mm，尚需实物公差和打印变形验收。

GPU供电延长线改为Phanteks PH-CB8V_BK 500mm，从右侧绕过转接线和顶扇M4螺钉；ATX24为Phanteks PH-CB24P_BK 500mm，EPS4+4为Akasa08-40BK，CPU只接正确4pin半边。未用的半头、第二PCIe头以及Molex/FDD链不能在装配时剪掉或凭空消失，需按模型中的外围余线区收纳。公开线长是否含插头、余线真实堆放和线材柔性没有由CAD证明。

## 尚未解决的关口

1. ADT-Link R83SL40cm选用真正短x8公端，避免把长x16公端硬塞进照片中的短槽。原厂STEP端头及75.45/108mm固定孔距已引入，但公端耳/夹条及其前固定螺钉仍碰CPU保护/散热代理；**转接线暂缓采购**。R83SF和K83候选也没有证实清除干涉。照片中插槽与散热器相对位置须量实物；约1.17mm只是早期圆整坐标下的裸公端相切量，不包含固定件、公差和真正装配净距，不能当作‘上移一点就通过’。
2. 四条400mm转接带有真实闭合扫掠，仍经过底扇上方部分供气区域。Z32–65下部的垂直投影约占底扇有效圆盘29.5%（网格投影估计），**不是29.5%的风量损失结论**。热影响需继续优化/实测，不能宣称完全没有挡风，也没有CFD或温升结果。
3. 三条数据线改用LSATA24/609.6mm，为插头及维修留长，余线固定于左后理线篮；盘3到hub的150mm原厂链仍需实配。头长、扣片、手指及自然弯曲的门槛保留在BOM/检查报告。原厂PSU出口Y96至工程gland Y82至少还有14mm未计长；EPS规划294.309mm的完整路径下界已到308.309mm，超过示例原厂300mm且未计接头，因此原厂300 EPS不获放行。采购需确认原厂EPS≥350mm、优选400mm的固定线配置，或重新安排中转；这是一项供货/设计条件，不是已确认现货。
4. 照片不能认证主板PCIe开口、插深、GPIO/开机针脚、风扇针脚及电流限制。R83SL为短x8，不再要求槽末端开口容纳x16。M.2照片标注与卖家带宽表有冲突，不承诺全部x4。
5. 25mm真实风扇采用26mm保守代理；底扇每孔总垫2mm、顶扇隔距总6mm，按实测补垫以保持原栈高。打印孔/螺母/嵌件、胶垫、承载、蠕变和运输振动均未做实物验收。

最终需在完全脱离净化器的状态下，做CPU/GPU并发、三盘读写/启动、PCIe稳定性、温度、降频及噪声验收。BOM为工程选型与备料表，不含未核价格，不代表已购买。
