# R6 已知问题与改进顺序

状态：2026-11-14，Asia/Singapore。工程原型；**几何检查未通过，未制造放行**。

1. **转接端头与 CPU40 保护空间干涉。** ADT-Link R83SL 短 x8 公端、耳/夹条及前固定件侵入 CPU 保护空间。不能缩小 40mm 保护、移动照片基准或忽略碰撞来声称通过。转接线采购暂缓；先量实板插槽、散热器及线头。
2. **原厂 EPS300mm 路径不够。** 原规划 294.309mm 从工程 gland 到中转，少算 PSU 前面到 gland 至少 14mm。完整最低 308.309mm 尚未含接头，已超过 300mm。须确认原厂固定线 ≥350mm、优选400mm，或重排；未确认的加长版本不当作现货。
3. **下部转接带挡风。** Z32–65 区间的投影约占底扇有效圆盘29.5%，这是几何投影估计，不能解释为29.5%风量损失。需要布局改进和热测试。
4. **主板与线缆仍是估计接口。** DS_2501 照片版次不一，端口约有1–2mm误差；针脚、插深、风扇电流、SATA共享、M.2带宽及线材弯曲均待实物核对。未知值继续保留未知。
5. **维护前置不能省略。** 第一盘前抽需断电、拔头停放、拆前/左皮及对应紧固件、拆左前柱底/顶螺钉，柱先向前16mm取下。GPU取出需拆顶盖/顶扇并停放8pin头，再脱槽上拔。不是热插拔设计。
6. **结构、电气、散热与噪声尚未验收。** 打印材料、公差、螺母、法兰、蠕变、运输和实机负载待确认。须脱离净化器进行 CPU/GPU 并发、三盘读写与启动、PCIe稳定性、温度/降频和噪声测试。

原始失败组数量与明细见 `../evidence/r6-review.json`。公开模型省略第三方端头；失败摘要来自包含端头的原始审阅模型，不因省略而改变。
