# R9 问题处理与验证边界

`v0.4.0-r9` 的本次 CAD 与公共几何字节检查已通过：39 组整机检查基线、分配罩底板修正后的 23 组局部复验，以及全部资产重新导出分别记录；最终报告 41 条记录（39 条基线、1 条局部复验汇总、1 条导出完整性）均无失败，43 个打印项网格封闭，STEP 回读 782/782 个有效实体。完整线路最小预算余量为 25.434mm，超过 25mm 门槛。范围和增量来源以[实际报告](../evidence/current-review.json)及[发布验证](../evidence/publication-verification.json)为准，实物与制造尚未放行。

## 接受范围

CAD 记录应分别说明正常装配、空气保护域、拆卸扫掠、完整线长与余线体积。STEP 有效、网格闭合、浏览器能打开和 GitHub 发布成功各有用途，均不能代替实物验收。

实物验收至少覆盖实际主板版次和接口、收到的原厂电源与线材、每盘原生螺钉进入量、打印件和薄片装配、夹持与绝缘、带载维护、PCIe 供电/协商/稳定性。散热测试应记录室温、各风扇转速、三盘同时读写以及 CPU/GPU 同时负载时每盘的稳态与峰值温度，核对实际硬盘型号的厂家限值；不能用单个平均盘温代替最热盘，也不能把厂商最大风量当成装机风量。

[R8 历史发布](https://github.com/ericxreator/kiwinest/releases/tag/v0.3.0-r8)及[R8结构记录](r8-changes.md)保留其原始检查与尚未完成的实物门槛。R9 重建后，R8 的检查数量、投影比例和线长结果不直接作为新布局结论。
