# R8 问题处理与验证边界

`v0.3.0-r8`工程原型保持原5825U板、CPU40、三盘直连和250 × 250 × 275mm目标，x8电气链路和至少20mm完整线长剩余量均为硬要求。包含原厂端头的完整模型通过25组CAD检查，22段完整预算达到余量门槛，最小约21.770mm；STEP回读731/731实体有效，40/40打印网格闭合。实际范围与受控接触见 [`current-review.json`](../evidence/current-review.json)，公开几何及浏览器验收见[发布检查](../evidence/publication-verification.json)，详细结构见 [R8改动](r8-changes.md)。实物与制造尚未放行。
