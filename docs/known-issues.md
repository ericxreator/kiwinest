# R7 问题处理与验证边界

R7保留原5825U板、CPU40、三盘直连和250 × 250 × 275mm目标。当前实际整机结果见 [`current-review.json`](../evidence/current-review.json)，R6失败记录见 [`r6-review.json`](../evidence/r6-review.json)。

| R6问题 | R7处理 | 验证边界 |
| --- | --- | --- |
| x8转接端头/螺钉碰CPU保护 | R23SR短x4端头与新支架；保持原板/插槽/CPU坐标 | 原厂完整端头8.089mm、前螺钉5.983mm名义净距；代价是链路x8→x4；实板供电/协商/信号稳定性待验 |
| EPS原厂300mm漏算出口段后不够 | 竖向4pin中转头位于X103.8..113.3；前侧延长线转折X123，保留完整线径与GPU上拔空间 | 原厂完整预算286.282/300mm，延长线497.321/500mm；延长线仅余2.679mm，须实线确认 |
| 底部四条400mm带穿GPU供气 | 官方目录30cm、R23SR两带回折重排，原保护风区保留 | 同口径投影见airflow-current；几何投影不等于风量或温升 |
| 旧线束占CPU侧新风 | GPU固定线绕CPU上缘，SYS线在前侧下降，EPS从保护圆外绕行 | 采用实际线径/弯曲半径代理检查，不缩CPU新风圆 |
| 出口隔离通道难以装入成品接头 | 分体半管、可拆屋顶及EPS14.75 × 5.5mm/ATX16.5 × 12mm底板开边槽，成品线侧放 | 底板槽只切线材专用区，未扣冷气域；拆装扫掠只覆盖明确动作，顶框完整拆出及密封仍须实物确认 |
| ATX/EPS/GPU走线相互交叉 | ATX接头转为后侧进线、前侧出线；EPS接头竖放、低位跨线后升至Z188；GPU保留底开U形槽 | 当前路径与全部实体的最终结果见current-review；接头姿态、线束截面和最小弯曲半径仍为工程代理 |
| GPU原厂线跨上拔通道 | Z193底开U形槽与可拆软绑带；上拔前将原厂300mm线自由段前移停放，中转接头固定 | 正常预算297.021/300mm，停放298.051/300mm；停放仅余1.949mm，软线变形、实际余量、全程移动和绑带保持力仍待实物验证 |
| ATX24原厂前面出口过渡未完整建模 | 保留当前工程出线点；已建模131.792mm，另计14mm未建模出口段、24mm接头与15mm装配余量，总预算184.792/300mm | 14mm只是长度余量，尚未证明PSU前面至假定出线点的实体、隔离或装配；不得据整机CAD通过扩大为全部线束验证 |
| PSU模块空气域未包含机架边界 | 补入实际固定后左柱/螺母墙面；不豁免任何线缆 | 冷气域仍连通，后左局部侧隙2mm；不宣称模块3.4mm名义间隙处处成立，不代表流量达标 |

实板照片版次/端口误差、原厂出口、实际线长口径、最小弯曲半径、余线收纳与绝缘、打印公差/承载/蠕变/振动、PCIe稳定性、无净化器条件下的温度/降频/噪声，目前均未做实物验收。制造状态保持未放行。

第一盘维修仍须断电拔头，拆前/左皮及对应紧固件、左前柱底/顶螺钉，再将柱向前16mm取下；GPU须拆顶盖/顶扇、拔下并停放8pin延长线头，再松开底部软绑带、送出预留余量，将原厂300mm线自由段前移停放且保持中转接头固定，之后才解除夹具、脱槽上拔。没有把这些真实前置删除来宣称独立热抽取。
