# R9：三盘散热优先的重新布局

R9 解决三盘缺少强制风路、顶部风扇受电源限宽和底座复杂的问题。它保留主板、显卡、CPU 40mm 保护、完整 K83UP-TL x8 端头与所有原厂线束，重新安排硬盘、电源、风扇和余线区。`v0.4.0-r9` 是已通过本次 CAD 与公共几何检查的工程原型；实物与制造尚未放行，本文不沿用 R8 的检查数量。

## 硬盘

三盘的连接器转向后方，原生安装面与四颗 6-32 螺钉继续使用。前置 92mm NF-A9 通过分配罩强制供气；盘体两侧形成 5 / 7 / 7 / 5mm 四条名义通道，中央连续高度 82mm，总截面 1968mm²。安装横条留在上下两端，不再横挡主要入口。

后集风腔在 SATA 头上方汇流，沿电源右侧上升后进入顶扩散罩。按原厂静态固定框投影扣除遮挡，保守净口约 2192.51mm²，大于四通道合计的 1968mm²；200mm 外框尺寸没有被当作可用通风面积。后部每盘各有电源口、数据口两片独立小检修盖，电线穿真实开边密封口；密封和软线仍须实物验收。

## 200mm 顶扇和简洁四脚

电源绕长轴滚转 90°，释放顶部宽度；原交流接口与排风面仍朝后，已知百叶面通向左侧外气窗。后左立柱与固定支承随之重排，电源不支承在可抽盘架或余线篮上。

顶扇采用 NF-A20 PWM 200 × 200 × 30mm 裸框，移除可拆防振垫，保留局部 0.5mm 原厂标签包络。官方 CAD 仅用于本地验证原创保守代理和间隙，不随发布分发。完整 x8 套管继续保留，主体从 255mm 调至 257mm，四个独立脚从 20mm 调至 18mm，总高仍是 275mm。

四圆脚取代连成一圈的底座，底部 120mm 风扇保留。滤网改为向右抽出，最低导轨距桌面名义 8mm，实际进气和防振仍待测量。

## 维护与完整线材

前风扇先右移再前抽；分配罩再前移 6mm、右移 12.1mm、前抽，五阶段保留前左柱与上方集线器。第一盘另拆前左柱下段并向前移 16mm，上段、集线器、余线篮及其余立柱保持安装。其他两盘无需移动该柱段。

底扇完整 PWM 中转头移到分配罩抽出路径右侧，底扇原线与 SYS 信号末段在盘锁工具扫掠后方抬高再转向前方。盘锁检查增加 L 形扳手的插入段与转动包络，检查时盘体、托架、原生螺钉及这些正常线材仍在位；实际工具和手部操作仍须试装，最终坐标与结果以本次报告为准。

每盘电源口、数据口两片后盖逐片拆卸。每次只剥对应密封和拆一颗螺钉，向后移 1.5mm、向右移 10mm，再抬高并横移到公共抽出通道，最后向后抽出。其余小盖及正常线材保持原位。开边槽让盖从完整线束旁离开，不要求将成品 SATA 头穿过小孔。之后只拔本盘两只接头并停放对应完整尾段，固定原厂串线和其他盘保持在位。详细顺序见[当前设计](design.md)。

三根数据线在背皮内侧的浅槽使用实际完整曲线与放大到 5.9mm 的截面生成，不用整块包络挖空。名义径向间隙为 0.2mm，本次最大名义槽深约 0.55mm、最薄外壁约 1.85mm，高于 1.8mm 检查下限；这些数值不构成线材贴合或打印强度验收。

六组原厂出口均从电源面开始构造完整源段，分体出线件为成品线束留开放安装方向；全部原厂分支、标准延长线和余线继续保留。已完整布置的商品线路分别核算中心线、接头占长与装配余量，剩余长度门槛提高到 25mm。未用 EPS 半头、Molex/FDD 与散线按完整库存和上方收纳体积保留，不声称所有导体或盘线都已实测建模。预算与体积不能代替实际线长口径、弯曲、盘线和工具空间。

## 验证与许可

本次先以原厂 STEP 重建并完成 39 组整机检查。随后发现前分配罩底板与后遮罩仅沿四段棱线相接，STL 非流形；底板延伸到后遮罩全厚下方后，完成 23 组局部复验，只改变该件及两个依赖扫掠，其余 176 个存储几何与检查域保持相同。全套 STEP、STL、GLB 和回读再次执行：最终报告 41 条记录（39 条基线、1 条局部复验汇总、1 条导出完整性）均无失败，43 个打印项网格封闭且绕向一致，STEP 782/782 个实体有效。该记录保留同次整机基线并明确局部增量，不宣称修正后又完成一次全量重建。

公共模型包含 417 个原创或工程代理节点，17142 个保留 accessor 的字节核对一致，厂商节点数据未遗留。21 组加工项、32 条完整线路预算和最小 25.434mm 余量由本次报告生成。详情由[检查报告](../evidence/current-review.json)、[公开几何审计](../evidence/public-geometry-audit.json)、[顶扇核对](../evidence/top-fan-verification.json)及[发布验证](../evidence/publication-verification.json)记录；公开预览省略的原厂端头仍留在本地完整检查。实际热、噪声、打印承载、蠕变、绝缘、原厂出口、PCIe 供电与 x8 协商尚未验收，制造状态未放行。
