# 当前原创 CAD

本目录的原创机箱零件、金属法兰与工程代理采用 **CC BY 4.0**；作者 ericxreator，项目 https://github.com/ericxreator/kiwinest 。许可正文见 `../LICENSES/CC-BY-4.0.txt`。

`parts/` 内零件各有STEP与STL。部分文件名沿用R6工程标识，当前数量、几何与检查版本以 `../evidence/current-review.json` 为准。文件未自动安排打印朝向、支撑或切片；BOM材料仅为原型建议，不能把网格有效当成可直接量产。

`PSU_R6_REPLACEABLE_1mm_METAL_FLANGE_NOT_PRINT.step` 与同名用途DXF是1mm金属法兰，不能用普通打印件替代。

`kiwinest-public.glb` 为原创箱体、五金与线缆工程代理，省略两个第三方端头及复用厂商曲面的泡棉压接代理，且移除它们的二进制数据。完整检查使用含原厂端头的本地模型；公开可见模型不能单独构成碰撞或制造结论。请先读 `../docs/known-issues.md`。

`fabrication/` 是原创非打印加工件：0.8mm FR4下压条（STEP及平面DXF）、绝缘硅胶泡棉原片（1.5mm平片STEP/DXF，按外形和两孔裁切），以及两片主板下位OD9钢制沉头承载垫（STEP）。钢垫的沉头轮廓以STEP为准；不能用平面轮廓替代其阶梯尺寸。泡棉名义装配高度为1.4mm；复用厂商线束曲面的受压代理仅供本地完整CAD验证，不随公开预览或加工文件分发。这些零件需要材料、公差、绝缘、预压、拉脱与载荷验证，不能用普通打印件直接替代。

R8完整ATX出口和GPU出口共用可拆分叶形通道，替代R7的GPU独立U形槽。原厂GPU主线保持安装姿态即可避开卡片上拔区；卡端8pin插头及延长线自由段仍需先拔下并停放。通道拆盖顺序、顶部模块及线缆服务姿态见设计文档。出口坐标、可用线长、实际盘线、打印强度和热表现仍待实物验收。
